# Giorno 14 - Fondamenti di HTML e CSS

Questa cartella contiene 15 esercizi introduttivi per imparare a creare pagine web con HTML e CSS. Gli esercizi procedono dai primi elementi HTML fino alla struttura semantica di una pagina completa.

| --- | --- | --- |

## Come usare gli esercizi

1. Apri la cartella di un esercizio.
2. Avvia `index.html` nel browser per gli esercizi 8-15.
3. Apri il file HTML direttamente nel browser oppure con l'estensione Live Server di VS Code.
4. Consulta i commenti presenti nei file HTML e CSS: spiegano le parti principali del codice.

## Convenzioni CSS

- La maggior parte degli esercizi utilizza un foglio di stile esterno chiamato `style.css`.
- Nel foglio HTML il collegamento si trova normalmente nell'elemento `head`.
- Le classi CSS cominciano con un punto, ad esempio `.evidenziato`.
- Gli ID CSS cominciano con il cancelletto, ad esempio `#protagonista`.

## Obiettivi di apprendimento

Al termine della serie dovresti essere in grado di:

- distinguere e usare i principali elementi HTML;
- organizzare i contenuti con titoli, liste, immagini, tabelle e moduli;
- applicare colori, spaziature, bordi e font con CSS;
- comprendere classi, ID e priorità dei selettori;
- utilizzare elementi semantici per migliorare struttura e accessibilità;
- leggere e modificare una pagina HTML completa con uno stile esterno.
