# Giorno 1 - Introduzione a Java

Questa cartella contiene gli esercizi introduttivi su struttura di un programma Java, tipi di dato, stringhe e costanti.

## Indice degli esercizi

| Esercizio | Argomento |
| --- | --- |
| [MainStructure.java](src/main/java/Day1/MainStructure.java) | Struttura di una classe e metodo `main` |
| [MetodoMain.java](src/main/java/Day1/MetodoMain.java) | Metodo `main` e metodi `static` |
| [StampaSequenza.java](src/main/java/Day1/StampaSequenza.java) | `print` e `println` |
| [TipiStatici.java](src/main/java/Day1/TipiStatici.java) | Tipizzazione statica ed errori in fase di compilazione |
| [TipiPrimitivi.java](src/main/java/Day1/TipiPrimitivi.java) | Tipi primitivi Java |
| [Overflow.java](src/main/java/Day1/Overflow.java) | Errori di overflow |
| [Conversioni.java](src/main/java/Day1/Conversioni.java) | Conversioni implicite ed esplicite |
| [Caratteri.java](src/main/java/Day1/Caratteri.java) | Tipo `char` e Unicode |
| [StringImmutabile.java](src/main/java/Day1/StringImmutabile.java) | Immutabilità delle stringhe |
| [StringConfronto.java](src/main/java/Day1/StringConfronto.java) | Differenza tra `==` e `equals()` |
| [Concatenazione.java](src/main/java/Day1/Concatenazione.java) | Concatenazione di stringhe |
| [ConfrontoTipi.java](src/main/java/Day1/ConfrontoTipi.java) | Tipi primitivi e oggetti |
| [Dichiarazioni.java](src/main/java/Day1/Dichiarazioni.java) | Dichiarazioni multiple e convenzioni |

## Come usare gli esercizi

Apri il progetto `day-01` in IntelliJ IDEA o in un altro IDE Java, quindi avvia il metodo `main` della classe che vuoi esercitare.
